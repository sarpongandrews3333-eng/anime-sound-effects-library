# Anime Sound Effects Library

A searchable collection of anime-style sound effects for video editing and code-assisted video generation.

## Contents
- `audio/` — organized MP3/WAV sound effects
- `video-source-clips/` — original MP4 reference clips
- `sounds.json` — machine-readable catalogue of every audio file
- `sound-effects-index.csv` — spreadsheet-friendly index
- `CLAUDE.md` — instructions for Claude-assisted video workflows
- `LICENSE-STATUS.md` — rights and redistribution warning

## Use with Claude
Read `CLAUDE.md` and `sounds.json`. Select sounds that match the scene, then download the actual audio file from the repository. Do not assume that a filename alone makes an audio file available.

Raw GitHub URL pattern:
`https://raw.githubusercontent.com/sarpongandrews3333-eng/anime-sound-effects-library/main/<path>`

Replace `<path>` with the exact path from `sounds.json`. If Claude cannot fetch external URLs in its current environment, ask the user to upload the chosen sound files.

## Important
All audio files are marked `Unverified`. Public repository visibility does not grant permission to redistribute copyrighted sounds. Check the source terms and obtain permission where needed.
