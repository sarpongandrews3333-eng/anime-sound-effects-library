# Publish to GitHub

1. Create a public repository named `anime-sound-effects-library` under `sarpongandrews3333-eng`.
2. Extract every part ZIP into the same folder, merging folders when prompted. Keep the folder structure.
3. Open a terminal in the extracted `anime-sound-effects-library` folder and run:

```bash
git init -b main
git add .
git commit -m "Add initial Anime SFX library"
git remote add origin https://github.com/sarpongandrews3333-eng/anime-sound-effects-library.git
git push -u origin main
```

If you use GitHub's website instead, upload the extracted repository contents while preserving folders.
